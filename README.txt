ArtVista - Angular 22
1) npm install
2) npm start        (http://localhost:4200)
Mock mode is ON (src/app/core/mock.ts -> USE_MOCK). Login with any password:
  admin@x.com -> Admin | artist@x.com -> Artist | anything else -> Collector
Set USE_MOCK=false and API in src/app/core/auth.ts to use your real Web API.
